# Contributing to Enterprise WhatsApp Automation Engine

Thank you for your interest in contributing to this project! We welcome improvements, bug reports, and feature requests.

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Clone your fork** locally:
   ``bash
   git clone https://github.com/your-username/whatsapp-automation-engine.git
   ``
3. **Create a branch** for your feature or bug fix:
   ``bash
   git checkout -b feature/amazing-feature
   ``
4. **Make your changes** and test thoroughly with sample data.
5. **Commit your changes**:
   ``bash
   git commit -m ""feat: add amazing feature""
   ``
6. **Push to your branch**:
   ``bash
   git push origin feature/amazing-feature
   ``
7. **Open a Pull Request** describing your changes in detail.

## Coding Guidelines

- Keep the code clean, readable, and well-commented.
- Follow PEP 8 guidelines for Python code.
- Ensure no sensitive client or personal data is committed.
